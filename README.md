VIBEWAVE Music Application
A modern, feature-rich music streaming application with a sleek dark-themed interface.

📋 Overview
VIBEWAVE is a comprehensive music streaming platform that provides users with an immersive audio experience. The application features a responsive design, intuitive controls, and a beautiful dark theme with customizable background options.

🚀 Features
Core Features
Music Player: Full-featured audio player with play/pause, skip, volume control, and progress bar

Playlist Management: Create, manage, and organize playlists

High-Quality Audio: Support for high-fidelity audio streaming

Cross-Platform: Responsive design works on desktop, tablet, and mobile devices

Interface Features
Dark Theme: Beautiful matte and shining black themes

Customizable Background: Toggle between matte black and shining black backgrounds

Floating Music Elements: Animated music notes and visual effects

Responsive Design: Adapts to all screen sizes

Additional Pages
Legal Center: Comprehensive legal information (Terms of Service, Privacy Policy, etc.)

Cookie Policy: Detailed cookie settings and management

Help Center: FAQ and support resources

About Page: Company information and team details

🛠️ Technologies Used
HTML5: Semantic markup structure

CSS3: Advanced styling with animations and transitions

JavaScript: Interactive functionality and dynamic content

Font Awesome: Icon library for UI elements

Google Fonts: Typography
